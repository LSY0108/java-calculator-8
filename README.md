# java-calculator-precourse

## 구현할 기능 목록
1. **입력값이 비어있거나 `null`인 경우 `0`을 반환한다.**
2. **구분자(쉼표 `,` / 콜론 `:`)로 숫자를 분리하고 합산한다.**
3. **커스텀 구분자(`//문자\n`)를 지정하여 숫자를 분리하고 합산한다.**
4. **잘못된 입력은 예외로 처리한다.**
   > `IllegalArgumentException` 을 발생시킨 후 애플리케이션 종료한다.(System.exit() 호출 금지)
   - 숫자가 아닌 값이 포함된 경우
   - 0 또는 음수가 포함된 경우(양수만 허용)
   - 커스텀 구분자 형식이 잘못된 경우(예: `"//;\r1;2"`, `"//\n1,2"`, `"//;;\n1;2;3"`)
   - 구분자 연속 사용 (`"1,,2"`, `"1::2"`, `"//;\n1;;2"`)
   - 문자열 시작 또는 끝이 구분자인 경우(`",1,2"`, `"1,2,"`, `"//;\n;1;2"`, `"//;\n1;2;"`)
